# Очистка базы данных от несуществующих изображений

## 🧹 Назначение

Скрипт проверяет все записи в таблице `trips` которые имеют поле `img`, и удаляет ссылки на файлы которые не существуют на диске.

## 🚀 Использование

```bash
# Из корня проекта
pnpm cleanup:images
```

Или напрямую:

```bash
cd apps/api
pnpm tsx src/trips/cli/cleanup-images.ts
```

## 📋 Что делает скрипт

1. **Подключается к базе данных** (использует `DATABASE_URL` из `.env`)
2. **Находит директорию с изображениями** (автоматически)
3. **Проверяет каждую запись** в таблице `trips` где заполнено поле `img`
4. **Если файл не найден**:
   - Удаляет ссылку из базы данных (`img = NULL`)
   - Выводит информацию в консоль
5. **Показывает статистику** после завершения

## 🔧 Требования

- Заполненный `.env` файл с `DATABASE_URL`
- Доступ к базе данных PostgreSQL
- Существующая директория с изображениями

## ⚠️ Важные замечания

- Скрипт **только удаляет ссылки** из базы данных, но не удаляет файлы
- Скрипт **не удаляет** сами файлы изображений (даже если на них нет ссылок)
- Все изменения в базе данных **необратимы** (сделайте backup если нужно)

## 🛠️ Для разработчиков

Скрипт использует следующие пути для поиска директории с изображениями (по порядку):

1. `apps/web/public/assets/images` (из корня monorepo)
2. `../web/public/assets/images` (из папки api)
3. `../../web/public/assets/images` (относительно скрипта)

Первый существующий путь будет использован.
